# Кат-сцены функций — промпты картинок

Каждая панель — отдельная картинка. Назови файл как указано (cut_<сцена>_<N>) и пришли, я сожму в .webp и вставлю. Пока картинки нет, в игре показывается заглушка с описанием кадра.

Общие правила для всех: стиль корейской манхвы, тёмное фэнтези, фиолетовая палитра, **без текста и без пузырей** — реплики игра рисует сама. Главный герой — один и тот же парень (как Призванный в игре): приложи к промпту его картинку, чтобы лицо совпадало.
