# Опрос: механика героев «как в Idle Heroes» (5 ноября 2026)

1. Что берём из Idle Heroes: **звёзды слиянием** (копии + любые герои-«корм»). Фракции/ауру, отряд из 6 и снаряжение — НЕ берём.
2. Уровень союзника: **золото + Дух** (вторая валюта, падает с врагов).
3. Кто бьёт в бою: **все нанятые** (как сейчас).
4. Звёзды: **1★–15★, длинно** — после 10★ ещё 5 ступеней «пробуждения».
5. Слияние: **1–5★ только копии этого героя, с 6★ — копии + корм** (любые другие герои).
6. Корм: **тратится лишняя копия** другого героя (дубль), сам герой у игрока остаётся.
7. Новая звезда даёт: **только рост урона** (без потолка уровня, навыков и нового облика).
8. Дух: **падает с боссов** (страж этажа).
