# Опрос по интерфейсу (200 вопросов) — ответы пользователя, 2026-11-05

Применять после окончания опроса. Порядок блоков: экран боя → профиль → меню → прокачка → портал → артефакты → сумка → питомцы → карта → PvE → настройки → окна/награды → звук/анимации/обучение.

## Экран боя (1–20)

3. Крит — крупнее и другого цвета + тряска экрана + надпись «КРИТ!» + вспышка на монстре (всё сразу).
4. Золото с монстра — **монеты летят к счётчику**.
5. HP монстра — **числа + процент**.
6. Урон по HP — **белый след плавно отстаёт**.
7. Рядом с именем монстра — **только имя, у стража/босса иконка**.
8. Таймер босса — **круглый таймер у имени**.
9. Провал босса — **красная надпись + кнопка повтора**.
10. «Вызвать босса» при фарме — **под полосой HP**.
11. Волна — **ромбики + «Волна N/10»**.
12. Стрелки ‹ › у этажа — **убрать, переход только через карту**.
13. Заряд ульт союзников — **ромбики под героем, как на макете**.
14. Ульта союзника — название ульты + крупный арт героя на секунду + эффект на монстре + затемнение фона (всё).
15. Имена союзников на поле — **всегда, мелко**.
16. Тап по союзнику — **ничего, тап идёт по монстру**.
17. Смерть монстра — **падает и тает**.
18. Появление стража — **плашка «СТРАЖ» на весь экран**.
19. Мега-босс — своя музыка, крупнее, фазы со сменой вида, золотая полоса HP.
20. Тап по плашке «Этаж» — **открывает карту Башни**.
21. Офлайн-отчёт — **окно при входе с наградами**.
22. «×2 за рекламу» в офлайн-отчёте — **да**.
23. Активные баффы — **иконки под золотом справа**.
24. Число справа вверху (⚔) — **только DPS отряда**.
