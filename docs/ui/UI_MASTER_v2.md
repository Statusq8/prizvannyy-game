# UI MASTER — «Призванный: Башня Гачи»
Версия 2.0 · 04.11.2026 · Рабочий мастер-документ для передачи Claude

## Назначение и статусы
Этот документ фиксирует решения UI, явно принятые в доступной переписке. Он не заменяет полный GDD и не является архивом дословно всего чата. Иллюстрации — визуальные макеты, а не готовые разрезанные игровые ассеты. «Предварительно утверждён» означает, что дизайн подходит как основа, но может быть уточнён. Позднее экран «Карта Башни» был утверждён в переписке; его окончательное изображение не удалось однозначно сопоставить с доступными файлами, поэтому старые варианты A/B помечены как неутверждённые.

## Глобальная дизайн-система (этапы 1–2, №1–20)
- Смешанный стиль: фэнтези + манхва + объёмные кнопки. Чёрная сталь, фиолетовые кристаллы, гравировка, металл, камни, магическое свечение.
- Главный экран боя: главный герой впереди, союзники за ним; способности автоматические, без кнопок ручного запуска, только индикаторы.
- Четыре средние квадратные кнопки с резными углами, примерно 60–68 dp, только иконки: верхняя левая — меню персонажей и улучшений; верхняя правая — настройки и профиль; нижняя левая — PvE-режимы и рейтинги; нижняя правая — карта Башни.
- Часть второстепенных разделов в отдельном полноэкранном меню. Разделы открываются полноэкранно, с кнопкой «Назад».
- На главном экране сверху золото; отдельная декоративная плашка этажа и полоса HP босса. В ходе правок добавлена плашка числового урона по образцу золота; убрать надпись «ДПС» и значки «+» рядом с ней.
- Анимация нажатия кнопки: вдавливание + свечение + звук.
- Общий визуальный принцип последующих экранов: единая огромная Башня, непрерывно видимая сквозь интерфейс по всей высоте; не разбивать фон на несколько несвязанных изображений.
- Макеты вертикальные мобильные. Готовые ассеты впоследствии должны экспортироваться отдельными прозрачными PNG; нельзя считать цельный UI-скриншот набором ассетов.

## Этап 3. Главное меню (№21–28) — утверждено
- Полностью закрывает бой, имеет собственный фон.
- Разделы вертикальным списком декоративных карточек: **Прокачка, Артефакты, Сумка, Питомцы**. В исходном ответе слово «сумма» трактовалось как «Сумка», что подтверждено последующими экранами.
- Иконки в рамках разных цветов по разделам. Названия разделов показываются только при выборе (в позднейших экранных макетах верхние вкладки показаны с постоянными подписями — это визуальное расхождение, которое нужно проверить перед экспортом ассетов).
- Кнопка «Назад» сверху слева. Внутри открытого раздела показывать только относящиеся к нему валюты.
- Открытие: быстрое появление с фиолетовым свечением.

## Этап 4. Прокачка (№29–40) — предварительно утверждена, выбран конкретный референс
- Прокачка главного героя и союзников; выбранный персонаж сверху, характеристики и улучшения ниже; выбор героя горизонтальной строкой маленьких портретов — раннее решение. В процессе просмотра референсов был выбран более подходящий **вертикальный список крупных карточек героев**; последнее визуальное решение имеет приоритет для общей страницы.
- Показывать все доступные характеристики; имя, уровень, ранг, звёзды, форму; значения до/после и процент прироста.
- Разноцветные кнопки по типу улучшения; стоимость внутри кнопки; одна кнопка улучшения с переключателем количества; без массового улучшения всех героев; валюта вверху справа.
- Сочетание металла, магических рун и декоративных панелей.
- Последний выбранный пользователем референс: **1000076909.png**. Карточки героев сохранять крупными, не сужать. Верхнюю часть сделать компактной, но **не уменьшать сами карточки**. Четыре уверенные вкладки с иконками. На каждой карточке: портрет слева, имя и параметры в центре, улучшение справа, значок фракции, ранг E–GOD на портрете, звёзды под аватаркой. Цвет звёзд единообразен в исходном состоянии, меняется при улучшении. Рамки усиливаются с редкостью, вплоть до роскошного GOD. В макете должны быть сравнимы высокие ранги SS/SSS/GOD; не допускать лишней надписи «SSS» над кнопкой улучшения.
- Примечание: на выбранном изображении могут встречаться неканонические имена/значения. Это референс композиции, не окончательная база героев.

## Этап 5. Артефакты (№41–54) — предварительно утверждены
- Сетка **4 артефакта в ряд**; крупная иконка, название, уровень, бонус. Рамки, свечение и особые эффекты в зависимости от редкости.
- Неполученные — силуэт с замком. Разделение «Полученные / Не полученные». Все полученные артефакты действуют автоматически, без меток «Активен».
- Души — в верхней строке рядом с названием. Улучшение открывается на **отдельной странице**, с переключателем ×1 / ×10 / ×100 / MAX сверху. Бонус: текущее → следующее и процент прироста. Отдельное компактное всплывающее окно с описанием.
- Кнопки улучшения красные с золотой рамкой, как у героев. Полупрозрачные карточки, через которые видна единая Башня. Визуальный акцент — красивые артефакты.
- Логика игры: все артефакты активны одновременно, улучшения за души, постоянны после ритуала; только артефакты повышают шанс критического удара (потолок 50%) и критический урон.
- Макет: **a_detailed_game_ui_mockup_in_the_same_dark_purple.png**. Значения бонусов на нём иллюстративные.

## Этап 6. Сумка (№55–70) — предварительно утверждена
- **5 предметов в ряд**; категории: Все / Материалы / Осколки / Расходники / Билеты / Особые; переключатель категорий — выпадающий список справа.
- Простые тёмные ячейки, внимание на предметах; редкость: рамка, свечение, особые эффекты; количество маленьким числом справа снизу. Пустые тёмные слоты.
- Нажатие — компактное окно с описанием и действиями «Использовать / Открыть / Продать / Подробнее» в зависимости от типа предмета. Количество: − / + / MAX. **Подтверждение для всех предметов**.
- Сортировка: редкость / тип / новые. Новинки — красный восклицательный знак. Строка поиска сверху.
- Башня видна через полупрозрачную сетку. Приоритет — удобная компактная сетка.
- Макет: **a_detailed_game_ui_screenshot_in_the_same_dark_pur.png**. Цифры и предметы — демонстрационные.

## Этап 7. Питомцы (№71–88) — предварительно утверждены после правки
- **Один большой выбранный питомец сверху, остальные ниже**. 3D-подобный рисунок с декоративной рамкой, карточка с характеристиками и анимированным фоном.
- Большая кнопка «Призвать / Отозвать»; выбор питомца и «Призвать». В бою одновременно **один питомец**.
- Редкость: рамки, магические эффекты, особые украшения высших рангов. Буква E–GOD в углу портрета. Звёзды **только после эволюции**.
- На общей карточке только уровень; подробные характеристики — в отдельном окне.
- **Строго две способности на питомца: одна активная, одна пассивная.** Крупные иконки с описаниями в нижней панели. Четыре иконки в первой генерации — ошибка, исправлена следующим макетом.
- «Улучшить» на карточке; одна кнопка с переключателем количества. Отдельная «Эволюция»; видна только текущая форма, будущие скрыты. Неполученные — силуэт с замком.
- Сортировка: редкость / сила / новые. Башня через полупрозрачные карточки. Главный акцент — большие изображения питомцев.
- Исправленный макет: **a_detailed_ui_screenshot_in_the_same_purple_gothic.png**. Приведённые на нём проценты и тексты умений не утверждены как игровые параметры.

## Этап 8. Портал призыва (№89–108) — предварительно утверждён
- Один общий портал для всех рангов: **каменные врата Башни с фиолетовым разломом**, большой центр экрана. Дополнительные кнопки видов призыва под порталом, если нужны; решение «один общий портал» приоритетнее предположения о нескольких независимых порталах.
- Призыв ×1 и ×10; кнопки разных цветов по типу; стоимость внутри кнопок; билеты в верхнем правом углу.
- Анимация: камера приближается к порталу, появляется герой; **уникальная анимация для каждого ранга**. Для ×10 сначала показывать по одному, затем общий экран результатов.
- Дубликат: надпись «Дубликат» и число копий. Первое получение редкого героя — короткая кат-сцена. «Пропустить» появляется через 1 секунду.
- Постоянная компактная таблица шансов, отдельная «История», шкала гарантии с наградой. При нехватке валюты кнопка отключена и показывается подсказка.
- Башня видна за порталом через магию. Акцент — портал + Башня + эффекты.
- Макет: **a_detailed_high_contrast_fantasy_game_ui_screen_i.png**. **Проценты выпадения на картинке декоративные, не утверждены.** В GDD SS открывается с 1000-го этажа, GOD с 4000-го — реальные шансы и правила доступны только из игровой системы, не из изображения.

## Этап 9. Карта Башни (№109–128) — ранняя версия; поздние изменения см. в дополнении v2
- Огромная вертикальная Башня с крупными платформами-этажами; карта открывается на текущем этаже, дальше ручная прокрутка. Количество видимых этажей зависит от масштаба.
- Пройденные этажи тёмные с отметкой; текущий этаж — анимированное окно Башни; закрытые — красные печати; боссы — корона и особая рамка; ключевой босс — анимированный силуэт.
- Нажатие на доступный этаж ведёт к нему. Повторное прохождение пройденных этажей возможно **с ограниченными наградами**. Награды обозначены только у ключевых этажей и боссов.
- Прогресс до следующего босса — полоса сверху; особые этажи — крупные тематические иллюстрации. Первый ритуал на 400-м этаже — особая кат-сцена.
- Текущий и максимальный этаж — одна строка «Этаж / Рекорд». Отдельная кнопка перехода к текущему этажу не нужна.
- Разные архитектурные зоны Башни по высоте; плавная прокрутка, параллакс, магические эффекты. Баланс красоты и навигации.
- Сгенерированы **два альтернативных макета**, пользователь пока не оценил: **a_dramatic_dark_fantasy_game_ui_screen_in_portrait.png** и **a_dramatic_dark_fantasy_mobile_game_ui_screenshot.png**.
- ВНИМАНИЕ: генерации содержат случайные несовместимые значения этажей, нелогичные статусы пройдено/закрыто, лишние блоки («Таблица шансов», «История») и произвольные награды. Не переносить эти ошибки в интерфейс. Функциональную логику брать из решений №109–128 и GDD.

## Что передать Claude при сборке
- Этот документ + выбранные изображения + полный GDD отдельно. Изображения использовать как **референсы**, не как исходники работающих кнопок.
- Сначала собрать структуру экранов и навигацию; затем экспортировать/нарисовать отдельные UI-элементы: фоны, рамки, кнопки в состояниях normal/pressed/disabled, значки, плашки, поля, сетки, модальные окна, индикаторы, декоративные части.
- Каждый экспортированный элемент: отдельный PNG с настоящим альфа-каналом, без запечённого общего фона; единые размеры и масштаб, если элементы одного класса. Дополнительно дать manifest: имя файла, экран, назначение, слой, размеры, точка привязки, интерактивное состояние.
- Не генерировать игровые значения (шансы, цены, уровни, имена, умения) из демонстрационных картинок. Подключать их к игровым данным.
- Отдельно согласовать экран результата призыва ×10, детальные карточки предметов/артефактов/питомцев, анимации, состояния кнопок и финальный экран карты.

## Правило обновлений
Любая следующая правка добавляется в документ с указанием номера этапа, старого и нового решения, статуса «черновик / предварительно / утверждено». Последняя явная правка пользователя имеет приоритет над ранней. Без явного согласования не объявлять макеты 100% финальными.


## ДОПОЛНЕНИЕ v2 — актуальные решения после этапа 9 (приоритет над старым текстом)

### Этап 9. Карта Башни — УТВЕРЖДЁННЫЙ КОНЦЕПТ, актуализация
- **Ровно пять этажей одновременно на экране**, каждый — широкая горизонтальная прямоугольная площадка/комната на всю доступную ширину, расположены вертикально один над другим.
- Это **реальное ощущение путешествия внутри одной Башни**: между этажами архитектурные перекрытия, колонны и проходы, а не пять разрозненных карточек на декоративном фоне.
- На каждом этаже видны персонажи и монстры, номер этажа и его состояние; текущий выделен золотым свечением.
- Биомы сменяются по мере подъёма (например, лес, затем другая зона); окружение площадок отражает текущую зону, но Башня остаётся цельным сооружением.
- Этажи боссов имеют значок босса и/или его крупную фигурку, особо важные боссы — уникальное оформление.
- Прокрутка вверх/вниз; при открытии показывать текущий этаж. Сохранять правила №109–128, если они не противоречат этому позднему решению.
- **Изображения tower_map_variant_A/B в ZIP не являются утверждённой картой.** Для финального пиксельного референса нужно отдельное подтверждённое изображение; не выдавать старые варианты за него.

### Этап 10. Экран боя — УТВЕРЖДЁННЫЙ, финальная композиция
- Вертикальный экран; вид **из-за спин всех героев и питомца**, смотрят на одного большого врага впереди.
- Один главный герой спереди по центру, четыре союзника позади/полукругом, один питомец; достаточно свободного пространства между каждым персонажем для чтения анимации. Главный герой крупнее союзников, но не заслоняет их.
- Фон арены меняется по зонам Башни. Не размещать нижнюю панель с кнопками навыков; навыки активируются автоматически, видны только компактные индикаторы под персонажами.
- **Верх:** золото в левом углу, числовой урон без подписи «DPS» и без кнопки «+» в правом углу; в центре компактная декоративная плашка этажа (без отдельного значка башни), волна/прогресс. У врага имя и HP, **без ранга и без значков баффов/дебаффов**; убрать лишний значок слева от HP.
- Убрать: нижние кнопки, ускорение, авто, выход, профиль в углу, лишнюю кнопку настроек вне утверждённой угловой кнопки. Не показывать постоянные HP союзников.
- В бою: крупные стилизованные числа урона; ручной тап — всплывающее число; попадание — искры, вспышка, короткий hit-stop; тряска экрана **разной интенсивности на критах, боссах и ультах**; ульта — короткий зрелищный эффект поверх боя; награды — небольшая всплывающая плашка.
- Босс: крупный противник, таймер, особая арена и эффекты. Никаких придуманных рангов у мобов.
- **Главный утверждённый визуальный референс:** `references/battle_APPROVED_latest.png`.

### Этап 10.1. Четыре угловые кнопки — УТВЕРЖДЕНЫ, точный последний вариант
- Все четыре кнопки квадратные с резными углами, чёрная сталь + фиолетовый кристалл/свечение, дорогая фэнтези-отделка. **Размер СРЕДНИЙ — строго как на последнем утверждённом макете, не уменьшать и не увеличивать.** Только иконки, без подписей.
- Верхняя левая — **скрещённые мечи** → меню персонажей/улучшений.
- Верхняя правая — **шестерня с кристаллом** → настройки/профиль (сам экран ещё НЕ согласован).
- Нижняя левая — **золотой кубок** → PvE и рейтинги.
- Нижняя правая — **высокая Башня с фиолетовым свечением** → карта Башни.
