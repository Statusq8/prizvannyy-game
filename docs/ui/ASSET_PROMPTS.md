# Промпты для PNG-ассетов интерфейса (к UI MASTER v2)

Сейчас весь интерфейс 0.40 нарисован кодом (CSS/SVG). Каждый элемент ниже можно заменить картинкой, не трогая логику.

**Общие правила для всех картинок**
- Отдельный PNG с настоящей прозрачностью (alpha), **без фона**, без текста и цифр — надписи и числа игра пишет сама.
- Стиль: тёмное фэнтези + манхва, чёрная сталь, фиолетовые кристаллы, гравировка, магическое свечение. Как на `references/battle_APPROVED_latest.png`.
- Элементы одного класса — одного размера и масштаба. Размер указан в пикселях (≈ ×3 от размера на экране).
- Кнопкам нужны 3 состояния: `normal`, `pressed` (вдавлена, ярче свечение), `disabled` (серая, без свечения).
- Класть в `assets/incoming/ui/` с именем из списка, затем написать «забери картинки».

Основа для промпта: *«game UI element, dark fantasy manhwa style, black steel with engraved runes, glowing purple crystals, ornate carved corners, isolated on transparent background, no text, front view, high detail»* + описание ниже.
