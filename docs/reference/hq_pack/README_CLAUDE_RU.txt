СЛОИ В ПРИЛОЖЕНИИ
0. Фон на весь портретный экран.
1. Верхние три ресурса и четыре вкладки.
2. Кнопка назад, заголовок Герои, переключатель количества.
3. Вертикально прокручиваемые ОДИНАКОВЫЕ полупрозрачные горизонтальные карточки.
4. На каждой карточке: портрет, сверху соответствующая рамка ранга, звёзды (отдельно), имя, уровень, сила, навыки.
5. Кнопка Улучшить справа по ВЕРТИКАЛЬНОМУ ЦЕНТРУ карточки; без плашки фракции справа.

ПРАВИЛА
- E тёмная сталь, D бронза, C изумруд, B сапфир, A аметист, S золото, SS алый рубин, SSS небесная платина, GOD божественный спектр.
- Звёзды — отдельный показатель эволюции, не встроены в рамку.
- Никаких кнопок «Освободить героя».
- Все цифры/характеристики/стоимости и динамические значения рендерить текстом в движке.
- Для ресурсов/вкладок уже были подготовлены отдельные PNG.

ВАЖНО: Это рабочий сборочный пакет, а НЕ финальный проверенный атлас. Некоторые листы ещё не нарезаны; рамки извлечены из утверждённого листа с программным удалением чёрной подложки. Перед релизом проверить границы, полупрозрачные свечения и пиксельную посадку на портрет. Не считать автоматическую нарезку идеальным исходным ассетом.
