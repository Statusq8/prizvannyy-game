# ПРИЗВАННЫЙ: БАШНЯ ГАЧИ — GDD 2.0 (6 ноября 2026, версия игры 0.94)

## 0. Где что лежит — один источник для каждого правила

| Что | Единственный источник | Правило |
|---|---|---|
| **Числа** (этажи открытия, шансы, цены, таймеры, множители) | `CONFIG` в `src/core.js` | В GDD чисел нет — только ссылки вида `CONFIG.ritual.floor`. Текущие значения — в `docs/CONFIG_VALUES.md` (генерируется `npm run docs`, руками не править). |
| **Правила** (что как работает) | этот файл | Меняется правило → правится этот файл в том же коммите, что и код. |
| **Экраны** (макеты, раскладка, детали) | `docs/ui/<ЭКРАН>.md` | BATTLE_HUD, CAMP, HQ, PORTAL, FORGE. |
| **Лор, герои, ролики** | `docs/LORE.md`, `docs/HEROES.md`, `docs/CUTSCENES.md`, `docs/START.md` | |
| **Что включено** | `CONFIG.disabled` + `docs/FEATURES.md` | |
| **История решений** | `docs/ANSWERS_200.md`, `docs/ui/ANSWERS_*.md`, `PROGRESS.md`, `docs/archive/GDD_v1.2.md` | Только история. При расхождении побеждает этот файл и `CONFIG`. |

Проверка: тест `tests/gdd.test.js` падает, если GDD ссылается на ключ, которого нет в `CONFIG`, или если `CONFIG_VALUES.md` устарел.
Приоритет: явное новое решение пользователя > этот файл > старые документы.

**Платформа:** Android, вертикальный экран; игра — веб (`index.html`), APK — обёртка WebView (`ANDROID.md`). **Жанр:** idle/tap RPG с коллекцией героев. **Тон:** тёмная манхва.

## 1. Суть и сюжет
Топ-геймера, первым в мире прошедшего финал игры, затягивает в Башню героем 1★. Цель — узнать правду о Башне. Проводник — Голос Башни (системные окна с глитчами). Подробно — `docs/START.md`, `docs/LORE.md`.
Первый запуск: пролог (4 кадра, можно пропустить) → ввод имени → первый враг.

## 2. Основной цикл
Тап по единственному врагу → урон главным героем → золото → прокачка героя и найм союзников → выше по Башне → открываются новые функции → ритуал меняет временный прогресс на постоянный.

## 3. Башня
- Башня **бесконечна** (`CONFIG.maxFloor` = null — вершины нет).
- На этаже `CONFIG.enemiesPerFloor` врагов подряд, последний — босс (страж) с таймером `CONFIG.bossTimeSec`. Проиграл по таймеру — остаёшься фармить, прокачиваешься.
- Каждые `CONFIG.biomeFloors` этажей — новая локация (`CONFIG.biomes`) и **мега-босс** на последнем этаже (HP × `CONFIG.finalBossHpMult`). Внутри локации залы меняются каждые `CONFIG.hallFloors` этажей.
- Рост HP врагов и золота — `CONFIG.enemyHpGrowth`, `CONFIG.floorCurve`, `CONFIG.goldGrowth`, `CONFIG.softcap`.
- Этаж 3: клетка с первым союзником (`CONFIG.cage`) — разбивается тапами.

## 4. Бой
- **На экране только главный герой** (+ питомец, когда откроются питомцы). Союзники не показываются: все **нанятые** союзники бьют невидимо (цифры и вспышки на враге). Отряда и резерва нет.
- Главный герой бьёт тапами (`CONFIG.maxTapsPerSec`); автоатака героя — только от артефакта «Клинок первого призыва».
- **Ульта только у главного героя** (`CONFIG.allyUlts` = false); способности героя — `CONFIG.abilities`.
- Криты: шанс и урон растут **только от артефактов**; шанс не выше `CONFIG.crit.maxChance`.
- У героев нет HP, они не умирают. Hit-stop — только визуально, отключается в настройках.
- Большие числа: K, M, B, T, затем aa, ab…

## 5. Открытие функций
Функции открываются по рекорду этажа (`CONFIG.unlocks`) и до открытия **полностью скрыты**. Открытая функция остаётся открытой после ритуала. В начале — мало функций, чтобы игра была понятной. Выключенные пока функции — `CONFIG.disabled` (см. `docs/FEATURES.md`).

## 6. Герои
- Редкости E → D → C → B → A → S → SS → SSS → GOD; старшие выпадают только после рекорда `CONFIG.rarityGates`.
- Список героев — `CONFIG.allies` (лор — `docs/HEROES.md`); фракции и стороны — `CONFIG.factions`, `CONFIG.sides`.
- Уровень — за золото (временный, сбрасывается ритуалом). Ранг — за осколки Башни (`CONFIG.ranks`, постоянный, поднимает потолок уровня).
- **Звёзды как в Idle Heroes:** до `CONFIG.maxStars`; слияние копий этого героя (`CONFIG.starCopies`) + корм из любых героев (`CONFIG.starFodder`). Звёзды дают только DPS героя (`CONFIG.starDpsBonus`).
- Эволюция — `CONFIG.evolution`.

## 7. Портал
- Открывается на `CONFIG.unlocks.portal`, островок в лагере. Экран — `docs/ui/PORTAL.md`.
- Призыв **только билетами** (на событийном баннере — фонарями); ×1 и ×10. **Рецептов нет** (решение 06.11).
- Шансы и гарантии — `CONFIG.portal` (`odds`, `pityA`, `pityS`, мягкая гарантия `softS`); гарантии у баннеров раздельные. Баннеры — `CONFIG.portal.banners`.
- Показ: сетка карт открывается сама; новые и S+ — показ как в Raid.

## 8. Кузница и артефакты
- Кузница открывается на `CONFIG.unlocks.forge`, островок в лагере. Экран — `docs/ui/FORGE.md`. Вкладки (Артефакты, Руны, Алтарь, Кости) видны по мере открытия.
- **Артефакты как в «Крушителях подземелий»:** витрина из `CONFIG.artShop.slots` случайных ненайденных; купленный слот пустеет; «Обновить» стоит долю цены следующей покупки (`CONFIG.artShop.refreshDiv`); цена покупки растёт с числом найденных.
- **Две ветви:** души (`CONFIG.artifactFind`) и кровавая — за осколки Башни (`CONFIG.artShop.blood`, артефакты с `blood: true`). Покупки одной ветви не дорожают другую.
- Все найденные артефакты действуют одновременно, без слотов, уровни переживают ритуал. Список и эффекты — `CONFIG.artifacts`.
- Души до ритуала — с мега-боссов (`CONFIG.megaSouls`); первый мега-босс дарит первый артефакт.

## 9. Экономика
- **Золото** — временное: уровни и найм. **Осколки Башни** — с боссов (`CONFIG.materials`): ранги и кровавые артефакты. **Билеты** — со стражей, мега-боссов, заданий, офлайна. **Души** — постоянные: артефакты; неизрасходованные души дают бонус DPS (`CONFIG.souls.dpsPerSoul`).
- Офлайн-награда копится до `CONFIG.offline.maxSec`: отряд сам проходит этажи на авто-DPS, у непобедимого босса спускается и фармит. Показывается отчётом при входе.

## 10. Ритуал
- Открывается на `CONFIG.unlocks.ritual`, для запуска нужно дойти до `CONFIG.ritual.floor`.
- Сбрасывает этаж, золото, уровни и найм. Сохраняет героев и звёзды, ранги, артефакты, питомцев, руны, кости, рекорды и открытые функции.
- Награда — души (`CONFIG.ritual`); стартовый этаж поднимает артефакт «Врата восхождения».

## 11. Лагерь (меню)
Летающие островки как город Idle Heroes, мрачный стиль; один островок = одна функция, появляется при открытии. Кнопка «В БОЙ», профиль и настройки — в лагере. Подробно — `docs/ui/CAMP.md`. Штаб (прокачка героев) — `docs/ui/HQ.md`. Экран боя — `docs/ui/BATTLE_HUD.md`.

## 12. Поздние функции (выключены, вводятся по одной)
Задания и вход, магазин/рынок, PvE, руны, дерево «Искры Башни», события и сезон, Алтарь, алхимия, эхо, проклятые и тайные этажи, тотемы, питомцы и Теневая башня, кости монстров. Код есть, правила будут переписаны при включении — каждая функция проходит: лор → механика и числа в `CONFIG` → тесты → макет → сборка → раздел в этом файле.
Принято заранее: питомцы — один в бою, эволюция из фрагментов (`CONFIG.pets`); кости — 6 слотов на героя (`CONFIG.bones`). Никакого PvP и гильдий.

## 13. Сохранения
- Основное сохранение в localStorage, автосохранение в бою раз в несколько секунд, при сворачивании и после важных действий. Версия схемы — `CONFIG.saveVersion`, старые сохранения мигрируются.
- 3 циклические резервные копии раз в 5 минут + снимок перед ритуалом; повреждённое основное — подъём из последней целой копии.
- Android: дополнительно копия в файле приложения; если данные WebView стёрты — восстановление из неё (`ANDROID.md`).

## 14. Порядок работы
Укрепляем текущую версию, прежде чем добавлять механики: Android-сборка → сверка GDD и кода → разделение `core.js` на модули → тесты баланса → проверка на телефоне. Новые экраны — по одному: макет → листы деталей → сборка.
