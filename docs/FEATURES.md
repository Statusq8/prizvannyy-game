# Функции игры: что включено (с 0.77)

Решение 5 ноября 2026: «слишком много функций — всё отключаем, делаем по одной: лор, концепция, тесты, картинки».
Выключатель — `CONFIG.disabled` в src/core.js. Убрал ключ из списка → функция вернулась (код не удалён).

## Включено (база)
- Бой: тап по врагу, этажи, волны, стражи, автопереход.
- Золото; прокачка Призванного; найм и прокачка союзников (все нанятые бьют, ульта только у Призванного).
- Страница героя: уровень, звёзды (слияние как в Idle Heroes), умения.
- Профиль, настройки.

## Включено после 0.77
- portal — Портал (0.86, этаж 25), artifacts + forge — Кузница с витриной артефактов (0.93, этаж 50).

- 0.142 — expedition (Экспедиции, этаж 75); 0.143 — map (Карта, этаж 30), pve (Испытания, этаж 100), runes (Руны, этаж 100); 0.144 — totems (Тотемы, этаж 750); 0.145 — tree (Искры Башни, после 1-й регрессии); 0.146 — events (этаж 150), season (этаж 250, премиум за 💎); 0.147 — altar (Алтарь, этаж 300, без скрытых рецептов); 0.148 — alchemy (этаж 400); 0.149 — echo (Эхо Башни, этаж 500); 0.150 — curse (проклятые этажи, этаж 500, шанс 1%); 0.151 — secret (тайные этажи, этаж 750, раз в 500).
