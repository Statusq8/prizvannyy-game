# Функции игры: что включено (с 0.77)

Решение 5 ноября 2026: «слишком много функций — всё отключаем, делаем по одной: лор, концепция, тесты, картинки».
Выключатель — `CONFIG.disabled` в src/core.js. Убрал ключ из списка → функция вернулась (код не удалён).

## Включено (база)
- Бой: тап по врагу, этажи, волны, стражи, автопереход.
- Золото; прокачка Призванного; найм и прокачка союзников (все нанятые бьют, ульта только у Призванного).
- Страница героя: уровень, звёзды (слияние как в Idle Heroes), умения.
- Профиль, настройки.
