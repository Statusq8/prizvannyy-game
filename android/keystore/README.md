# Ключ подписи APK — НЕ ТЕРЯТЬ И НЕ ПУБЛИКОВАТЬ
Все версии приложения подписываются этим ключом. Если ключ потерять или поменять, Android не установит
обновление поверх старой версии — придётся удалять приложение, и прогресс (если не сделан экспорт) пропадёт.
Пароль лежит в `../gradle.properties` (pzKeystorePassword). Репозиторий с ключом держите ПРИВАТНЫМ.
