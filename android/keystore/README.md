# Ключ подписи APK — НЕ В РЕПОЗИТОРИИ
С 0.94 файл ключа (.jks) и пароли в репозиторий не кладутся (`.gitignore`). Ключ хранится:
- в секретах GitHub Actions (`PZ_KEYSTORE_BASE64`, `PZ_KEYSTORE_PASSWORD`, `PZ_KEY_PASSWORD`) — для сборки в Actions;
- у владельца в надёжном месте (облако/флешка) — копия на случай потери.

Все версии подписываются одним ключом: если его потерять или поменять, Android не поставит обновление поверх,
придётся удалять приложение (прогресс сохранится только через экспорт сохранения).
