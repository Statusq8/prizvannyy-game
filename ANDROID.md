# Сборка Android APK

Приложение — обёртка WebView над той же игрой (`index.html` в корне). Пакет `ru.prizvannyy.game`, только вертикальный экран,
полноэкранный режим, кнопка «Назад» закрывает окна игры, сохранение при сворачивании + копия в файле приложения,
экспорт сохранения через «Поделиться». Все версии подписываются одним ключом, поэтому обновления ставятся поверх без потери прогресса.
**С 0.94 ключ и пароли в репозитории не хранятся** — только в секретах GitHub и у владельца (см. android/keystore/README.md).

## Секреты для сборки в GitHub (один раз)
Settings → Secrets and variables → Actions → New repository secret:
- `PZ_KEYSTORE_BASE64` — файл ключа .jks в base64 (`base64 -w0 release.jks`)
- `PZ_KEYSTORE_PASSWORD` — пароль хранилища, `PZ_KEY_PASSWORD` — пароль ключа
- `PZ_KEY_ALIAS` — необязательно (по умолчанию `prizvannyy`)
Без секретов сборка сразу останавливается с понятной ошибкой.

## Вариант 1 — GitHub (автоматически)
1. Залить папку проекта в приватный репозиторий GitHub.
2. Вкладка **Actions** → «Сборка APK» → **Run workflow** (сборка только по команде, автоматически не запускается).
3. Через ~5 минут: открыть запуск → блок **Artifacts** → скачать `Prizvannyy-<версия>-apk` (zip с APK).
4. На телефоне открыть APK → разрешить установку из этого источника → установить.

## Вариант 2 — Android Studio
1. `npm run build && cp index.html android/app/src/main/assets/index.html`
   Создать `android/local-signing.properties` (в .gitignore): `storeFile=/путь/к/release.jks`, `storePassword=…`, `keyPassword=…`
2. Android Studio → Open → папка `android` → дождаться синхронизации Gradle.
3. Build → Build App Bundle(s) / APK(s) → Build APK(s). Файл: `android/app/build/outputs/apk/release/app-release.apk`.

## Проверка после установки (QA-14/QA-15)
- 15 минут автобоя без зависаний и обрезания персонажей.
- Свернуть на несколько часов → окно «Пока вас не было» с наградой.
- Поставить следующую версию APK поверх → прогресс на месте.
