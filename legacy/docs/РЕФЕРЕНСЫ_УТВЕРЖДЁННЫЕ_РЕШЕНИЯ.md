# РЕФЕРЕНСЫ — Призванный: Башня Гачи

## Визуальные решения (утверждены 03.11.2026)
- Персонажи: внешний вид максимально точно по присланным картинкам; без самостоятельной смены стиля.
- Анимация: комбинация покадровой и скелетной/по отдельным частям. Для каждого героя уникальная idle-стойка.
- Боевые арены: меняются каждые 50 этажей.
- Смерть противников: падение и постепенное растворение, как в референсах.
- Первый анимируемый бой: Теневой мечник против Теневого волка.
- Формат: вертикальный 9:16. На полноценной сцене Призванный со спины и максимум четыре видимых союзника; все нанятые герои учитываются в DPS.
- Спрайт-листы по 4 изображения: ключевые позы, а не полноценные промежуточные кадры.

## Присланные примеры
- Дракон, крылатые воины, сфера, щитоносец, теневой убийца, волк, мечник, демон, многоглазые чудовища, глаз Бездны.
- Светлый зал, осквернённое святилище, арена Бездны.
- Изображения лежат в `01_РЕФЕРЕНСЫ_И_КАРТИНКИ/` с исходными именами; идентификация каждого файла по имени не гарантирована.

## Техническое ограничение
Референсы не являются готовыми ригами, слоями или спрайтовыми последовательностями. Их нельзя автоматически считать рабочими анимациями.
