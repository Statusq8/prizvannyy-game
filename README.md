# Призванный: Башня Гачи

Idle/tap RPG для Android (вертикальный экран), первая реализация — веб. Разработка с нуля по GDD (`docs/GDD.md`).

**Играть:** тестовая ссылка https://claude.ai/artifact/P1gpv86aLCsaXhnEvdMeC9 (открывается в аккаунте владельца) или файл `index.html` в браузере.

## Как продолжить работу (в том числе с другого аккаунта)

1. Подключи репозиторий `Statusq8/prizvannyy-game`.
2. Скажи Claude: «Продолжаем игру, прочитай `README.md`, `PROGRESS.md` и `docs/GDD.md`».
3. Claude продолжает со следующего шага из `PROGRESS.md`.

## Правила работы

- Один источник для каждого правила (GDD 2.0, раздел 0): правила — `docs/GDD.md`, **все числа — только `CONFIG` в `src/core/00*_config_*.js`** (в GDD — ссылки на ключи), экраны — `docs/ui/*.md`.
- Поменял правило или число → в том же коммите поправь GDD/CONFIG и запусти `npm run docs` (обновляет `docs/CONFIG_VALUES.md`). `npm test` проверяет, что GDD и CONFIG не разошлись.
- После каждого готового шага: обновить `PROGRESS.md`, закоммитить и запушить.
- После каждой готовой версии обновлять тестовую ссылку и давать её пользователю: `npm run build`, затем публикация `index.html` артефактом (slug `b2419820-a7c9-41a8-b481-ce9d839385fa` (с 0.87; старая ссылка BF6Cu7… больше не обновляется), republish с этим slug — publish_files с index.html) (та же ссылка, сохранение игры в ней не теряется).
- APK собираем только по прямому запросу (см. `ANDROID.md`).
- Уточняющие вопросы — в чате, с вариантами ответа.
- **Экраны — точь-в-точь как макет пользователя** (решение 06.11): перемерить макет (позиции и размеры каждого элемента в долях ширины, `cqw`), детали из листов не растягивать криво (края с иконками — `border-image`), фон на высоком экране делить на верх/низ. Пример — src/market.js. Сравнивать скриншот с макетом до сдачи.

## Структура

- `index.html` — текущая игра (один файл, собирается `npm run build` из `src/` и `assets/`).
- `src/core/` — логика по модулям (без интерфейса, тестируется в Node): `00a–00e` CONFIG, `02_numbers`, `03_bonuses`, `04_allies`, `05_state`, `06_combat`, `07_meta`, `08_liveops`, `09_progression`, `10_summon`, `11_economy`, `12_ritual`, `13_altar_misc`, `14_save`, `15_format_export`; порядок — `src/core/ORDER`. `src/core.js` — загрузчик для Node. `src/template.html` — интерфейс.
- `assets/` — картинки игры (фон-зал Башни: оригинал и сжатая копия). Новые картинки — в `assets/incoming/`.
- `tests/` — автотесты ядра, `tools/sim.js` — симуляция баланса, `tools/artifact.js` — копия для тестовой ссылки.
- `docs/GDD.md` — дизайн-документ 2.0 (правила; старый 1.2 — `docs/archive/`), `docs/CONFIG_VALUES.md` — текущие числа (генерируется). `docs/ART_PROMPTS.md` — промпты и имена файлов для всех картинок. `docs/reference/` — исходные материалы автора: концепт 40 героев, макет боя, лист зон, арт Каэрона и Призванного (`art/`).
- `android/` — обёртка WebView для APK, `.github/workflows/android.yml` — сборка APK по команде.
- `PROGRESS.md` — что сделано и что дальше.

Старая версия игры (0.10–0.12, папки `legacy/`, `work/`, `releases/`) удалена 2026-11-04; она сохранена в ветке `archive/old-version-0.12`.

## Команды

- `npm test` — тесты, `npm run build` — сборка `index.html`, `npm run sim` — симуляция 30 минут игры.
