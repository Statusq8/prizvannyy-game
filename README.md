# Призванный: Башня Гачи

Idle/tap RPG для Android (вертикальный экран), первая реализация — веб. Разработка с нуля по GDD (`docs/GDD.md`).

**Играть:** тестовая ссылка https://claude.ai/artifact/PQ1TUDafn5n85GQJMihdbJ (открывается в аккаунте владельца) или файл `index.html` в браузере.

## Как продолжить работу (в том числе с другого аккаунта)

1. Подключи репозиторий `Statusq8/prizvannyy-game`.
2. Скажи Claude: «Продолжаем игру, прочитай `README.md`, `PROGRESS.md` и `docs/GDD.md`».
3. Claude продолжает со следующего шага из `PROGRESS.md`.

## Правила работы

- Идём строго по плану из раздела 15 GDD, по одному этапу.
- Числа из раздела 16 GDD (TBD) не выдумываем как окончательные — только временные значения в `CONFIG`.
- После каждого готового шага: обновить `PROGRESS.md`, закоммитить и запушить.
- После каждой готовой версии обновлять тестовую ссылку и давать её пользователю: `npm run build`, затем `node tools/artifact.js <файл>` и публикация этого файла артефактом с `url` = тестовая ссылка выше (та же ссылка, сохранение игры в ней не теряется).
- APK собираем только по прямому запросу (см. `ANDROID.md`).
- Уточняющие вопросы — в чате, с вариантами ответа.

## Структура

- `index.html` — текущая игра (один файл, собирается `npm run build` из `src/` и `assets/`).
- `src/core.js` — логика (без интерфейса, тестируется в Node), `src/template.html` — интерфейс.
- `assets/` — картинки игры (фон-зал Башни: оригинал и сжатая копия). Новые картинки — в `assets/incoming/`.
- `tests/` — автотесты ядра, `tools/sim.js` — симуляция баланса, `tools/artifact.js` — копия для тестовой ссылки.
- `docs/GDD.md` — дизайн-документ. `docs/ART_PROMPTS.md` — промпты и имена файлов для всех картинок. `docs/reference/` — исходные материалы автора: концепт 40 героев, макет боя, лист зон, арт Каэрона и Призванного (`art/`).
- `android/` — обёртка WebView для APK, `.github/workflows/android.yml` — сборка APK по команде.
- `PROGRESS.md` — что сделано и что дальше.

Старая версия игры (0.10–0.12, папки `legacy/`, `work/`, `releases/`) удалена 2026-11-04; она сохранена в ветке `archive/old-version-0.12`.

## Команды

- `npm test` — тесты, `npm run build` — сборка `index.html`, `npm run sim` — симуляция 30 минут игры.
