# Призванный: Башня Гачи — версия 2 (новый старт)

Новая разработка игры с нуля по GDD v1.0. Старая версия (v0.11.0) лежит в корне репозитория и не используется.

**Играть:** открой `v2/index.html` в браузере телефона или компьютера.

## Как продолжить работу (в том числе с другого аккаунта)

1. Подключи репозиторий `Statusq8/prizvannyy-game`.
2. Скажи Claude: «Продолжаем игру, прочитай `v2/README.md`, `v2/PROGRESS.md` и `v2/docs/GDD_v1.0.md`».
3. Claude продолжает со следующего шага из `PROGRESS.md`.

## Правила работы

- Идём строго по плану из раздела 15 GDD, по одному этапу.
- Числа из раздела 16 GDD (TBD) не выдумываем как окончательные — только временные значения в `CONFIG`.
- После каждого готового шага: обновить `PROGRESS.md`, закоммитить и запушить.
- APK собираем только по прямому запросу.
- Уточняющие вопросы — в чате, с вариантами ответа.

## Файлы

- `index.html` — текущая игра (один файл, собирается `npm run build` из `src/`).
- `src/core.js` — логика, `src/template.html` — интерфейс, `tests/` — автотесты, `tools/sim.js` — симуляция баланса.
- `PROGRESS.md` — что сделано и что дальше.
- `docs/GDD_v1.0.md` — дизайн-документ.
